# LLPM

**This CLI is retired.** LLPM's skills live on as the `llpm` bundle in [britt/agent-skills](https://github.com/britt/agent-skills):

```
/plugin marketplace add britt/agent-skills
/plugin install llpm@britt
```

No further development happens in this repository. Git history here is the archive — the CLI's source, the skills it used to ship, and the design behind its retirement are all preserved as-is.

See [`docs/plans/2026-09-01-llpm-retirement-design.md`](docs/plans/2026-09-01-llpm-retirement-design.md) for the full retirement design and rationale.
